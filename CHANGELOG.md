# What's new in 5.0.0

A bigger, nicer updater: a redesigned window, a portable version, and release notes you can read before you update.

## New
- **What's new dialog.** When a new version of the updater is out, you now see its full release notes first and choose **Update and restart** or **Later**. After an update, the notes show once more so you know what changed. Turn it off in Settings.
- **Portable version.** A zip you can unpack anywhere and run, no installer. Everything it saves stays in a `Data` folder beside the app, and it never installs itself over anything. It tells you when a new version exists and links to the download.
- **Skip this build.** A broken nightly? Press **Skip this build** and the updater waits for the next one. You can still install the skipped build from the Builds tab.
- **Recent installs.** The Builds tab now lists your last installs with dates, so you always know what you came from.
- **F5** checks for updates.

## Improved
- **A much better look.** A soft color wash on the status card that follows the state, icon chips on the tiles and settings, grouped settings, tab icons, a deeper Mica backdrop and a gentle entrance animation.
- **A calmer app icon.** Flatter and softer so it sits naturally next to the other icons on your PC.

## Good to know
- Updates from 4.1.0 install as usual. The release-notes dialog appears for updates from 5.0.0 onward, because older versions can't read it.
